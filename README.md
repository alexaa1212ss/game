# Cavegame Reborn Alpha

Official Windows player installer and signed updates.

[Download the Windows installer](https://github.com/alexaa1212ss/game/releases/latest/download/CavegameRebornSetup.msi)

Download availability begins after the Windows build and installation checks pass. Install for your Windows account, open Cavegame Reborn, choose a nickname, and press Play. No Node.js, development tools, server download, manual configuration, or ZIP extraction is required.

Your login identity stays protected on your Windows account. Your inventory/progress is saved on the game server. No email or password is required. Export an encrypted identity recovery file before replacing your PC.

This is an early alpha. The installer is not yet Authenticode-signed, and Microsoft reputation warnings may appear. Never disable antivirus or add exclusions. Updates have independent Ed25519 signatures and SHA256 file/archive verification.

The current Alpha server runs on the operator's PC through a temporary tunnel. Availability depends on that PC. This is not yet 24/7 hosting.

Player release files and build scripts here are public. Private server files, databases, owner keys, and release signing private keys are excluded.
