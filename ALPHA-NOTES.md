Windows x64 alpha player installer. Download CavegameRebornSetup.msi, run it, then open Cavegame Reborn from your Desktop or Start Menu. Choose a nickname and press Play.

Per-user installation; no administrator rights requested. Bundled runtime: no Node.js installation needed. Signed application updates and protected device identity. Server saves progress.

Unsigned Windows publisher: a proper Authenticode certificate is still required. SmartScreen reputation warnings cannot be guaranteed away. Do not disable antivirus.

Temporary PC hosting, not 24/7. Early alpha; gameplay is still being tested. Server/developer material is not included. See the attached file audit and acceptance report for exactly what was tested.
