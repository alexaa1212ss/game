# Cavegame: Reborn — Closed Alpha 0.4.0

This update starts a fresh V5 Alpha season. Previous world/builds/inventory/economy remain privately archived; they are not part of the fresh season. Device identity and developer ownership remain intact. The separate offline game and saves are preserved.

- Accept the current Closed Alpha agreement explicitly before Play. Declining blocks access. Acceptance is versioned and recorded against the device/server identity. No invite code or manual tester approval is required.
- New deterministic cave networks and coherent deposits: accessible coal and iron, plentiful but less common gold, rarer discoverable diamonds, and deeper obsidian. Mines have wood supports; some distant mines contain spawner chambers. Aethersteel remains a Creative-only prototype.
- 100 sampled seeds passed progression, abundance, connectivity, spawn safety and structure checks. These are stratified samples, not a census of every tile or every possible seed.
- Ordinary players receive only nearby relevant terrain. Unknown minerals are masked; developer full-map routes stay restricted. Global mineshaft coordinates are no longer exposed to ordinary players.
- Correct four-stage mining cracks; quick mushroom harvest without square cracks; sword swing visuals; empty hotbar/hand selection and authoritative two-damage punches. Walking is about 3% faster as requested local tuning.
- Bounded crafting panel, matching expanded inventory slots, separated shop labels and viewport-clamped tooltips. Actual visual appearance still needs tester confirmation where automated browser rendering is unavailable.
- Green system/player help and red developer help. Online help lists supported commands.
- Player installer and signed updates contain client runtime only. Server, owner/signing keys, accounts, saves, moderation tooling and development evidence are excluded.

Current hosting is a temporary owner-PC Cloudflare tunnel. It requires the host window and PC to stay running; permanent free hosting has not been deployed. Installer/launcher Authenticode signing remains outstanding, so SmartScreen reputation warnings may occur. Never disable security software.
